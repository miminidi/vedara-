# Vedara Brand Brief

## FACT

The customer supplied:

- Brand name: `Vedara`.
- Logo: ornate golden/brown tree/woman/eye mark with `Vedara` wordmark.
- Main colors:
  - Purple: `#241336` — main accent, background, banners, panels.
  - Graphite: `#2B2B2F` — text.
  - Gold: `#C6A75E` — links, icons, text highlight, optional buttons.
  - Pearl: `#EDEAF4` — cards, substrates, soft backgrounds.
- Fonts:
  - `Prata` — mostly uppercase/headings.
  - `Arial` — interface/body text.
- Additional request:
  - Main app color should be white/pearl.
  - Lavender and lilac tabs/accents.
  - Purple active states.
  - Restrained gold highlights.
  - Place the logo at the top of the main/home screen.

## Product feeling

Premium, calm, feminine wellness, esoteric-but-clean, not medical-hospital, not aggressive fitness.

## RULE

The app should not be a random recolor. It needs a tokenized Vedara design system so future edits are made centrally.
