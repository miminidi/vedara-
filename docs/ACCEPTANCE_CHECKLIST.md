# Acceptance Checklist

## Build

- [ ] App installs dependencies successfully.
- [ ] App runs locally.
- [ ] `npm run build` passes.
- [ ] No TypeScript errors.
- [ ] No console errors during basic navigation.

## Core flow

- [ ] Onboarding opens for a first-time user.
- [ ] `Продолжить` stores onboarding completion.
- [ ] Home screen appears after onboarding.
- [ ] Bottom nav works.
- [ ] Home category cards open relevant screens.
- [ ] Purchases screen shows product filters.
- [ ] `Wellness Club` product card opens details.
- [ ] Mock purchase unlocks full access.
- [ ] Profile reflects demo/full subscription state.
- [ ] Useful material completion updates progress.
- [ ] At least one service request can be submitted in mock mode.

## UI

- [ ] Looks good at 390 px width.
- [ ] Looks good at 430 px width.
- [ ] Bottom nav does not cover important content.
- [ ] Cards do not overflow horizontally.
- [ ] Russian text is readable.
- [ ] Locked state is understandable.
- [ ] Visual style is close to the reference mood.

## Product boundaries

- [ ] No real payment claims.
- [ ] No medical diagnosis/treatment advice.
- [ ] No backend dependency in GOAL 001.
- [ ] No admin/chat/video features added.

## Demo readiness

- [ ] Can be shown to client on phone in under 2 minutes.
- [ ] User understands what is free/demo and what is paid.
- [ ] The product feels like a paid subscription ecosystem, not just a landing page.
