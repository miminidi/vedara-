# Vedara home screen spec

## Goal

Update the MVP main/home screen from generic wellness/nutribody reference style into Vedara.

## Structure

1. Pearl/lavender page background.
2. Top brand header:
   - Vedara logo at the top.
   - Optional notification icon on the right.
   - Tagline: `экосистема для твоего здоровья`.
3. Hero card:
   - title: `ТВОЙ ПУТЬ К ГАРМОНИИ`;
   - text: `Комплексный подход к телу, питанию, восстановлению и внутреннему балансу.`;
   - CTA: `Узнать больше`;
   - hero photo placeholder;
   - small gold/purple ecosystem badge.
4. Spaces row/cards:
   - BODY;
   - NUTRITION;
   - WELLNESS CLUB;
   - optionally REHABILITATION locked below or in carousel.
5. Premium CTA:
   - `VEDARA PREMIUM`;
   - `Полный доступ ко всем пространствам и возможностям экосистемы`;
   - `Оформить подписку`;
   - `от 5 900 ₽ / месяц`.
6. Progress:
   - four small rounded cards.
7. Bottom nav:
   - `Главная`, `Мои покупки`, `Vedara`, `Полезное`, `Профиль`.

## Visual target

Use `assets/reference/vedara-home-generated-reference.png` as the main visual reference.

Do not try to pixel-copy it. Rebuild it as real responsive components using tokens.
