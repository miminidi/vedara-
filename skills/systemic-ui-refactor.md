# Skill — Systemic UI Refactor

## Role

Refactor UI safely without rewriting the whole app.

## Process

1. Inspect current structure.
2. Identify duplicated visual styles.
3. Add token foundation.
4. Move repeated UI into components.
5. Move copy/data into config.
6. Replace old styles page by page.
7. Run build.
8. Report exact files changed.

## Principle

Prefer small stable refactors over dramatic rewrites.
