# Skill — Orchestrator

## Role

Coordinate all other skills and keep the project moving toward a working MVP.

## Priority order

1. Working app.
2. Mobile UX close to reference.
3. Clean product logic.
4. Safe health/wellness boundaries.
5. Simple code.
6. Future extensibility.

## How to work

Before coding:

- read `AGENTS.md`;
- read `MEMORY.md`;
- read active goal;
- inspect repository structure;
- identify stack;
- avoid unnecessary rewrites.

During coding:

- call product owner skill for scope decisions;
- call UI guardian skill for visual/layout decisions;
- call content-access architect for paywall/progress;
- call health safety guardian for risky copy;
- call mobile QA skill before final report.

After coding:

- run build/typecheck;
- check acceptance criteria;
- report with files and limitations.

## Stop conditions

Stop and report instead of inventing when:

- implementation requires real payment credentials;
- implementation requires real user medical data;
- the current repo stack conflicts with the default stack;
- assets are missing and cannot be legally copied.
