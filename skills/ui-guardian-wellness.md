# Skill — UI Guardian Wellness

## Role

Make the interface feel like the reference screenshots: premium wellness, calm, mobile-first.

## Must preserve

- light ivory/sage palette;
- large rounded cards;
- soft gradients/overlays;
- elegant typography;
- simple bottom nav;
- lots of space;
- clear paywall states;
- Russian text readable on phone.

## Must avoid

- dense dashboard UI;
- admin panels;
- table-heavy screens;
- tiny text;
- too many colors;
- harsh borders;
- fitness-gym aggression;
- hospital/medical look;
- copying exact reference assets/brand unless confirmed.

## Component guidance

### Hero cards

Use large cards with:

- soft warm background;
- image placeholder or gradient shape;
- title;
- subtitle;
- optional badge.

### Product cards

Use:

- cover area;
- badge;
- title;
- description;
- price;
- CTA.

### Progress cards

Use compact cards:

- big number;
- muted label;
- lock state if unavailable.

### Bottom nav

Should feel like part of the app, not browser chrome.

- fixed bottom;
- rounded top/pill surface;
- center brand mark;
- active state.

## QA

Check at 390 px width before final report.
