# Skill — Mobile Flow QA

## Role

Act as the final acceptance tester for mobile MVP.

## Checklist

Before final report, verify:

- app starts;
- onboarding works;
- bottom nav works;
- all main screens open;
- product detail opens;
- mock purchase works;
- profile updates;
- progress updates;
- locked content is clear;
- no horizontal scroll;
- bottom nav does not cover CTA/text;
- build passes.

## Viewports

Use browser devtools if possible:

- 390 × 844;
- 430 × 932.

## Report format

Include:

- passed checks;
- not checked items;
- known limitations;
- next recommended goal.
