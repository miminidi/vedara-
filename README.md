# Vedara Tracker Center Dock Pack

Пакет для следующего прохода Codex по текущему проекту Vedara MVP.

## Задача пакета

Не делать новый продукт и не менять бизнес-логику.  
Системно обновить:

1. Нижнюю навигацию:
   - Главная
   - Практики
   - Трекер
   - Клуб
   - Профиль

2. Сделать `Трекер` центральной акцентной кнопкой с эмблемой Vedara.

3. Зафиксировать правильный смысл разделов:
   - Главная = вход в Longevita Club + locked ecosystem blocks + tracker widget.
   - Практики = действия, уроки, материалы, протоколы.
   - Трекер = ежедневная отметка, привычки, состояния, календарь, отчеты.
   - Клуб = community hub.
   - Профиль = доступ, цели, настройки, заявки.

4. Применить обновленный брендбук Vedara Longevita.

## Что внутри

- `CODEX_MASTER_PROMPT.md` - основной промпт для Codex.
- `goals/GOAL_005_CENTER_TRACKER_DOCK.md` - формальный GOAL.
- `docs/` - правила IA, dock, бренда, UX, QA.
- `design-tokens/vedara-longevita-ui-tokens.css` - предлагаемые токены.
- `snippets/` - заготовки для navigation data, NavIcons и dock CSS.
- `reference/` - брендбук, референс интерфейса, SVG-логотип.

## Как использовать

1. Распаковать пакет рядом с проектом или добавить папку `docs/codex-packs/vedara-tracker-center-dock`.
2. В Codex вставить `CODEX_MASTER_PROMPT.md`.
3. Попросить Codex сначала прочитать `goals/GOAL_005_CENTER_TRACKER_DOCK.md`.
4. Не коммитить и не пушить до визуальной проверки скрина.
